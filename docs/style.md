# Source documentation style

The convention for this pack, enforced by `ruff` (`pydocstyle` rules, Google convention) and by
`tests/test_docstrings.py`. Vendored files under `mambair/archs/mambair*.py` are exempt — see
[`docstring-waivers.md`](docstring-waivers.md).

## The five rules

1. **Summary line first.** One imperative sentence, ends with a period, at most 100 characters,
   on the first line after the opening `"""`.
2. **Then the reason.** One to three lines of *why* — the constraint, the invariant, the trap —
   separated from the summary by a blank line. If there is nothing non-obvious to say, stop here.
3. **Sections in this order:** `Args:`, `Returns:`, `Yields:`, `Raises:`, `Attributes:`, `Note:`.
   Only the ones that apply. `args:` lowercase, one blank line before each section.
4. **Shapes, not annotations.** Write `` u: Input, shape ``(batch, channels, length)` `` — never
   restate the type that the signature already carries.
5. **Comments state invariants, not history.** A comment explains a property of the code as it is
   now, or cites the test that guards it (`see tests/test_scan.py`). It never narrates what the code
   used to do, and it never restates a measurement that lives in `README.md` or a design note.

## Worked example

This function is real; its docstring is the shape every Tier-1 symbol should take — the twelve
named in `tests/test_docstrings.py`'s `TIER1` table, which is where the gate actually looks.

```python
def selective_scan_fn(u, delta, A, B, C, D=None, z=None, delta_bias=None,
                      delta_softplus=False, return_last_state=False):
    """Run a selective scan.

    Resolves a backend on first use: ``mamba_ssm`` if importable, else the fused Triton kernel if
    the probe accepts it, else the chunked PyTorch scan. Calls below ``PROBE_MIN_TOKENS`` stay on
    the PyTorch tier, so a small first call cannot decide the tier for the process.

    Args:
        u: Input, shape ``(batch, channels, length)``.
        delta: Step sizes, shape ``(batch, channels, length)``.
        A: State transition, shape ``(channels, d_state)``; negative by convention.
        B: Input projection, ``(batch, groups, d_state, length)``, or ``(batch, d_state, length)``
            for a single shared group.
        C: Output projection, same layout as ``B``.
        D: Per-channel skip weight, shape ``(channels,)``, or ``None``.
        z: Gate for the SiLU-multiplied variant, shape ``(batch, channels, length)``, or ``None``.
        delta_bias: Per-channel bias added to ``delta`` before ``softplus``, shape ``(channels,)``.
        delta_softplus: Apply ``softplus`` to ``delta``.
        return_last_state: Also return the final state.

    Returns:
        Output of shape ``(batch, channels, length)``, or ``(output, last_state)`` with
        ``last_state`` of shape ``(batch, channels, d_state)`` when ``return_last_state`` is set.

    Raises:
        ValueError: If ``groups`` does not divide ``channels``.
    """
```

## What is deliberately not documented

ComfyUI node boilerplate (`INPUT_TYPES`, `IS_CHANGED`, `VALIDATE_INPUTS`, `execute`,
`define_schema`, `get_node_list`, `comfy_entrypoint`), tiny constructors, `extra_repr`, local
closures and one-line `load()` delegations. Their contract belongs to ComfyUI or to the signature.
The full list with reasons is [`docstring-waivers.md`](docstring-waivers.md); it is a decision
record, so adding a row is a reviewable act rather than an omission.

## Measuring things

Timings and memory numbers belong in `README.md` (generated by `python tests/bench.py --write`) or
in a design note kept beside the source. In source, cite the artifact instead of copying the number:

```python
#: Tokens per chunk in the pure-PyTorch scan. Tuned on a 6 GB laptop; re-tune with tests/bench.py.
CHUNK = 256
```
